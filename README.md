# marketing-YPF

Marketing workspace.

| Folder | What it is |
|---|---|
| [`video-studio/`](video-studio/README.md) | **Ya PakCik Video Studio**: Remotion + React + TypeScript + FFmpeg video templates for **Project A.M** (cinematic documentary) and **YaPakCik Frozen** (commercial and motion graphics). Exports 16:9 and 9:16. |

Quick start:

```bash
cd video-studio
npm install
npm run studio     # preview and edit in the browser
```

See [`video-studio/README.md`](video-studio/README.md) for the full beginner guide.
